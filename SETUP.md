# Переход на личные аккаунты

1. Аккаунт владельца для автоматического переноса уже задан: `himikmetan@gmail.com`.
2. В Firebase Console выберите проект `tochka-opory-2f30a`. В Authentication → Sign-in method включите Google. В Settings → Authorized domains добавьте `himikmetan-wq.github.io` без `https://` и пути.
3. В Firestore Database → Rules замените действующие правила содержимым `firestore.rules` и нажмите Publish. Старый общий раздел станет доступен только владельцу для чтения; правила обязательны для защиты личных записей.
4. Опубликуйте `index.html` в ветке GitHub Pages. При первом входе владельца старые записи автоматически копируются в его личный раздел. При обрыве перенос повторится при следующем входе. Старые данные останутся на месте в качестве резервной копии.
5. Проверьте с другим Google-аккаунтом: чужие записи не отображаются, новые записи сохраняются после обновления страницы, а у первого аккаунта ничего не меняется.

Если публикация на GitHub Pages происходит из корня основной ветки, любое обновление этой ветки публикует общую новую версию для всех по прежнему адресу. Сам репозиторий и Firebase-проект должны оставаться под контролем владельца.
